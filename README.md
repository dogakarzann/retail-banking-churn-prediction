# Retail Banking Churn Prediction

This repository contains data analysis and modeling for predicting customer churn in retail banking using credit card data.

## Project Structure
- `data/`: Contains the dataset.
- `notebooks/`: Jupyter notebooks for Exploratory Data Analysis (EDA) and Modeling.
- `src/`: Source code for data preprocessing, feature selection, evaluation, and other utility functions.

## Setup
Install the required dependencies and the local package using:
```bash
pip install -r requirements.txt
pip install -e .
```
*(Running `pip install -e .` ensures that notebooks inside the `notebooks/` folder can correctly import modules from the `src/` folder without any path issues).*
